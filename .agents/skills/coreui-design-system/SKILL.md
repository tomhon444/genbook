# CoreUI Design System
1. Inspect installed `@coreui/react` and `@coreui/coreui` versions and follow matching docs.
2. Prefer CoreUI React components for standard controls.
3. Define consistent colors, spacing, typography, borders, radii, and status tokens.
4. Define reusable app shell, sidebar, header, breadcrumbs, page title, cards, forms, tables, pagination, dialogs, alerts, badges, and empty states.
5. Ensure keyboard access, visible focus, labels, validation messages, semantic headings, and contrast.
6. Include loading, empty, error, success, and disabled states.
7. Do not mix UI frameworks without approval.
8. CoreUI React components using state/events belong inside a Client Component boundary (`'use client'`). Keep pages/layouts server-rendered where possible.
9. Import CoreUI CSS once in root layout as documented for the installed version.
10. Do not assume CoreUI PRO is available when only open-source packages are installed.

## Output
Component/pattern choice; responsive behavior; accessibility notes; files/components.
