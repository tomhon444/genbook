## บันทึกคำตัดสิน

เก็บ packet เดิมไว้ ส่งคำตอบแยกโดยระบุ sourceSha256, inputPacketManifestSha256, namesManifestSha256 และ itemId ของแต่ละรายการ พร้อมตัวเลือก เหตุผล ผู้รับรอง วันเวลา และหลักฐานจริง ชื่อ/ประเภทต้องระบุ field (`displayName` หรือ `documentType`) และรับรองแต่ละ fieldReviews แยกกัน การยืนยันชื่อไม่ยืนยันประเภท หากเปลี่ยนค่าระบุ proposedValue ด้วย ตัวเลือกทั้งหมดเป็นข้อเสนอสำหรับตรวจรับ ไม่ใช่ config เปิดสิทธิ์

ยังไม่มีตัว apply คำตอบจากชุดนี้เข้าฐาน ต้องตรวจหลักฐานและผูกคำรับรองก่อนขั้น implementation ถัดไป ข้อกำหนดไฟล์/ข้อมูลรอบสุดท้ายและบัญชีจริง T13 ยังต้องตรวจรับตาม AC2 เดิม
