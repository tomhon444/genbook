# T12 — ตารางตรวจรับ mapping และรายการผิดปกติ

จัดทำ 13 พฤศจิกายน 2026 (Asia/Bangkok) · [Ticket T12](../tickets/12-legacy-migration.md) · [ผลซ้อมและแผน cutover](local-legacy-migration.md)

สถานะ: **ร่างรอตรวจรับ** ช่องผู้รับรองที่ว่างไม่ได้หมายถึงอนุมัติ การทำตารางนี้ยังไม่เพิ่มเกณฑ์ผ่านจาก 3/6 และไม่ทำให้ข้อมูลจริงเข้าแอปหรือตั้งตัวนับ

อัปเดต 13 พฤศจิกายน 2026: [ตรวจเจาะปัญหา 55 รายการครบแล้ว](t12-anomaly-investigation.md) เติมข้อเสนอพร้อมหลักฐานในตาราง A02–A07 ของชุดเฉพาะเครื่อง ทั้งหมดยังรอตรวจรับ ไม่เปลี่ยนค่าต้นทาง

ตรวจ [กลุ่มเลขซ้ำ 1,308 กลุ่ม](t12-duplicate-investigation.md) และเติมข้อเสนอรายกลุ่มครบแล้วด้วย ผู้ใช้ยืนยันว่าไม่มี backup เพิ่ม ข้อเสนอเก็บข้อมูลที่กู้ไม่ได้แยกและกันเลขเดิมอยู่ในรายงานปัญหา 55 รายการ ยังไม่ใช่การรับรอง mapping/counter

ผู้ใช้ยืนยันแนวทางเก็บแยกเมื่อ 13 พฤศจิกายน 2026 แล้ว และ [ซ้อม preservation/reservation ผ่าน](local-legacy-preservation.md) ช่องตรวจรับ mapping บัญชี/หน่วยงาน/ชุด/สิทธิ์ในชุดตารางนี้ยังคงรอ เพราะเป็นคนละการตัดสินใจกับนโยบายเก็บข้อมูลที่กู้ไม่ได้

รอบต่อจาก T09 เพิ่ม [ตัวตรวจ mapping และ promotion จาก preservation](local-legacy-promotion.md) พร้อมแบบ JSON เฉพาะเครื่อง `.local/t12/mapping-78629b14-c361d059/` ตรวจพบเรื่องว่างอีก 1,845 รายการที่ไม่ผ่านเงื่อนไข metadata ของ importer ใหม่ ไม่แต่งเรื่องหรือทิ้งแถว ผู้ใช้ยังไม่ทราบความตรงกันของรหัสบัญชีคณะเดิม/ใหม่ จึงยังไม่กรอก approvals และคง 3/6
