## What to build

## Acceptance criteria

- [x] กรองและแบ่งผลค้นหาอย่างมีขอบเขต รองรับกรณีไม่มีข้อมูลและ input ผิด
- [x] รายการและจำนวนผลไม่รวมหนังสือที่ไม่มีสิทธิ์ โดยบังคับสิทธิ์บน server
- [x] เปิดรายละเอียดจากผลค้นหาได้ และการเข้าถึงโดยตรงยังถูกตรวจสิทธิ์
- [x] วันเวลาและตัวกรองตรงตามกติกาปีและ Asia/Bangkok ที่อนุมัติ
- [x] browser/HTTP tests ครอบคลุมทุกตัวกรองหลัก การใช้ร่วมกัน และการรั่วข้อมูลข้ามสิทธิ์
- [x] มือถือ/คีย์บอร์ดและ loading/error ทำงาน; lint, typecheck, เทสต์ผ่านและ QA ตรวจ
