## What to build

เจ้าของแก้เฉพาะข้อมูลที่อนุญาต และผู้มีสิทธิ์ตรวจประวัติรู้ว่าใครแก้อะไรเมื่อใด โดยไม่ทำเลขหรือข้อมูลเดิมหาย

## Acceptance criteria

- [x] server อนุญาตเฉพาะฟิลด์/สถานะ/บทบาทที่ตกลง ไม่ให้เปลี่ยนเลขโดยอ้อม
- [x] การแก้พร้อมกันถูกจัดการตามนโยบายที่อนุมัติ ไม่เขียนทับการแก้ของผู้อื่นเงียบ ๆ
- [x] บันทึกการเปลี่ยนแปลงและ audit แบบ atomic พร้อมแสดงก่อน/หลังตามสิทธิ์
- [x] ประวัติไม่เปิดรายละเอียดลับต่อผู้ไม่มีสิทธิ์
- [x] browser/HTTP tests ครอบคลุมแก้สำเร็จ ฟิลด์ต้องห้าม ข้ามสิทธิ์ และการแก้ชนกัน
- [x] มี feedback และการเข้าถึงที่เหมาะสม; lint, typecheck, เทสต์ผ่านและ QA ตรวจ
