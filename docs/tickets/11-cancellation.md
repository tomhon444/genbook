## What to build

เฉพาะเมื่อเจ้าของระบบยืนยันให้มีในรุ่นแรก: ผู้มีสิทธิ์ยกเลิกหนังสือพร้อมเหตุผล และเห็นสถานะ/ประวัติโดยยังคงอ้างอิงเลขเดิมได้

## Acceptance criteria

- [x] ตรวจผลจากงานกติกาก่อนเริ่ม; หากไม่รวมรุ่นแรก บันทึกว่าไม่ดำเนินการและไม่สร้างฟังก์ชันแทนการตัดสินใจ
- [ ] หากรวม: ตรวจสิทธิ์ สถานะ เหตุผล และจัดการคำขอซ้ำตามกติกาบน server
- [ ] ไม่ลบประวัติหรือใช้เลขกลับเงียบ ๆ; สถานะและ audit เปลี่ยนแบบ atomic
- [ ] หน้าจอแสดงผลยกเลิกและประวัติตามสิทธิ์ พร้อมกรณีปฏิเสธ
- [ ] browser/HTTP tests ยืนยันสำเร็จ ข้ามสิทธิ์ ส่งซ้ำ และผลต่อเลข; lint/typecheck/tests ผ่านและ QA ตรวจ
