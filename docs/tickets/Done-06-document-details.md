## What to build

ผู้ขอเลขบันทึกผู้รับหลายคน หน่วยงานรับเรื่อง ผู้ลงนาม ความลับและการเผยแพร่ แล้วเห็นรายละเอียดครบตามสิทธิ์จริง

## Acceptance criteria

- [x] รองรับผู้รับหลายคน หน่วยงานภายในหลายแห่ง และหน่วยงานภายนอกตามกติกาที่อนุมัติ
- [x] บันทึกผู้ลงนาม/ผู้ขอเลขและข้อมูลความลับ/เผยแพร่แยกจากสถานะการจัดสรรเลข
- [x] บังคับตารางสิทธิ์ทุก server operation และไม่รั่วข้อมูลผ่านรายละเอียดหรือการเดารหัสรายการ
- [x] เก็บ audit สำหรับการเปลี่ยนแปลงที่เกิดขึ้น และแสดง validation/loading/error ที่เข้าถึงได้
- [x] มี browser/HTTP tests กรณีครบถ้วน ข้อมูลผิด และสิทธิ์ข้ามเจ้าของ/หน่วยงาน/ความลับ
- [x] lint, typecheck, เทสต์เกี่ยวข้องผ่านและ QA ตรวจ
