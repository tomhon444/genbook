## What to build

บุคลากรภายในคณะเข้าสู่ระบบ เห็นตัวตนในพื้นที่ส่วนตัว และออกจากระบบได้จริง ตั้งแต่การยืนยันตัวตนถึงข้อมูลผู้ใช้งานและหน้าจอ

ขอบเขตพัฒนาที่ผู้ใช้ยืนยัน 12 พฤศจิกายน 2026: ทำ UI และ session ของระบบใหม่ใน localhost ด้วยบุคลากรสังเคราะห์ โดยแยกตัวเชื่อม identity ให้สลับเป็นบัญชีคณะได้ภายหลัง ใช้กฎสิทธิ์/ข้อมูลจาก T02 ที่รับรองแล้ว ไม่ดัดแปลง sandbox PHP ให้เป็น login bypass ใน Next.js production

## Acceptance criteria

- [x] รุ่น local เชื่อมบัญชีสังเคราะห์ผ่านตัวเชื่อม identity ที่แยกจาก production และบันทึกตัวตน/หน่วยงานเท่าที่จำเป็นอย่างปลอดภัย; ช่องทางคณะจริงตรวจใน T13
- [x] ผู้ไม่เข้าสู่ระบบและผู้ไม่มีสิทธิ์เข้าพื้นที่ส่วนตัวไม่ได้ทั้งทางเว็บและ HTTP
- [x] session หมดอายุ/ออกจากระบบแล้วไม่สามารถใช้ session เดิมเข้าถึงข้อมูล
- [x] มีสถานะกำลังทำงาน/ผิดพลาด ใช้งานมือถือและคีย์บอร์ดได้
- [x] มี browser/HTTP tests สำหรับสำเร็จ ปฏิเสธ หมดอายุ และออกจากระบบ โดยใช้ข้อมูลทดสอบ
- [x] lint, typecheck, เทสต์เกี่ยวข้องผ่าน และส่ง QA; รายงาน checks ที่ทำไม่ได้

## บันทึกความคืบหน้า

- 11 พฤศจิกายน 2026: สร้างไฟล์ติดตามจาก GitHub; ยังไม่มีหลักฐานปิดงานหรือเกณฑ์รับงานที่ผ่าน
- ผลตรวจ/หลักฐาน: ยังไม่มี
- 12 พฤศจิกายน 2026: ผู้ใช้ยืนยันให้เดินหน้าด้วยบัญชีจำลองและแยกบัญชีจริงเป็นงานก่อนเปิดใช้ จึงพร้อมเริ่มรุ่น local ตามกฎ T02 ที่ยืนยันแล้ว ไม่อ้างว่า T02 AC1 ผ่านหรือ T04 implementation เสร็จ
- อุปสรรคปัจจุบัน: ไม่มี blocker ต่อการเริ่มรุ่น local; production readiness ยังรอ [T13](./13-faculty-identity-release-gate.md)

- 12 พฤศจิกายน 2026 (implementation): เข้าสู่ระบบ/พื้นที่ส่วนตัว/ออกจากระบบด้วย CoreUI และ server-only identity adapter; ตัวจำลองแยก process loopback ใช้บัญชีสังเคราะห์สุ่ม ไม่ติดต่อฐานเดิมหรือคณะ ดู [คู่มือและหลักฐาน](../specs/local-sign-in.md)
- ตรวจรับ local: provider 9/9, browser/HTTP 6/6, production isolation 3/3 ผ่าน; typecheck/build ผ่าน; lint exit 0 มี warnings เดิมใน .agents/skills 96 รายการ scoped lint ของงานสะอาด
- QA อิสระผ่าน ไม่พบ Critical/High/Medium ที่ต้องแก้ในขอบเขต local ตรวจภาพ desktop/mobile แล้ว; production readiness และบัญชีจริงยังรอ T13 ค่า TTL 30 นาทีเป็น local default และ status เป็น startup snapshot
